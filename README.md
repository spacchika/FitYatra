# FitYatra

FitYatra is a modern Android app for tracking gym workout sessions, managing customized workout plans, and monitoring progress. It features:

- Pre-filled and user-expandable exercise database (categorized by muscle group)
- Customizable workout plans (3-day, 4-day, or custom)
- Set/rep/weight/time/rest tracking
- Customizable rest timers
- Deload week logic and suggestions
- Performance-based weight recommendations
- Calendar integration
- Local database with auto/manual backup to Google Drive, OneDrive, and local storage
- Modern Material Design UI

---

## Project Structure (Planned)
- `app/` – Android app source code
- `database/` – Pre-filled exercises and schema
- `docs/` – Documentation and wireframes

---

## Getting Started
1. Open this project in Android Studio.
2. Build and run on your device or emulator.
3. Configure backup options in the app settings.
